# 大纲思维导图（outline-mindmap）

[English](README.md) · **中文** · [插件介绍（可在 Obsidian 里直接打开的演示笔记）](插件介绍.md)

> **这是个人 fork**：在 [cimuyang/outline-mindmap](https://github.com/cimuyang/outline-mindmap)
> **v1.3.4** 的基础上增加了节点正文预览、节点内联 HTML、有序列表节点和若干健壮性修复；
> 笔记格式与插件 id 保持不变。当前 fork 版本：**1.5.0**。
> Fork 仓库：[SkyLarkkx/outline-mindmap](https://github.com/SkyLarkkx/outline-mindmap)

把 Markdown 笔记的标题大纲变成思维导图，支持双向实时编辑、点击定位和样式自定义。笔记是唯一的数据源，设置保存在插件自己的 `data.json` 中，不添加 frontmatter、标签或隐藏标记。本 fork 额外支持**悬停/固定预览节点正文**、节点标题里的**安全内联 HTML**，以及把**有序列表作为普通列表节点**显示。

![Outline Mindmap demo](demo.gif)

演示素材录制于旧版本；1.3.4 的布局方向已移至「样式设置」。

- 适用于 **Obsidian** 1.7.2 以上 · 桌面端与移动端 · **fork 版本 1.5.0（上游基础 v1.3.4）**
- 界面语言跟随 Obsidian：中文 / English 自动切换，无需任何设置

## 特色功能

### 本 fork 新增（与原版 v1.3.4 的区别）

- **节点正文预览**：鼠标悬停节点约 0.3 秒，预览该节点的直接正文；由 Obsidian 的 `MarkdownRenderer` 渲染，HTML、图片、表格、公式和内嵌内容与阅读视图一致。可固定成右侧面板，也可用工具栏的眼睛按钮打开/关闭；固定面板可拖拽缩放，触屏长按面板与固定面板相互独立。预览只读，不会写回笔记。
- **大图性能模式**：移动端总节点超过 500 时自动启用；首屏用可读比例聚焦第一个根分支，只创建视口附近的节点和连线。桌面端自动模式保持原样，设置页可改为始终开启或关闭。
- **节点内联 HTML**：节点标题支持 `<span style="…">`、`mark`、`font`、`strong`、`em`、`sup`、`sub`、`br` 等安全内联标签和受限 CSS。脚本、iframe、事件属性、`url()` 和块级 HTML 会被拒绝；节点标题里不支持完整 HTML 表格或图片。
- **有序列表节点**：`1.` / `1)` 列表项会作为普通列表节点显示，不显示序号；重命名/移动时保留源码 marker。新建有序兄弟项继承参考项的 delimiter，新建子项写 `-`，不自动重排源码编号。
- **正文表格修复**：预览正文会按公共缩进左移，Tab 缩进的 Markdown/HTML 表格不再被当成代码块；同时补充表格边框与单元格样式。
- **健壮性修复**：`==高亮==` 改用当前 Obsidian 的 highlight 变量并保留旧变量回退；含 HTML 的节点增加字宽余量，避免最后一个字被挤到下一行。

本 fork 继续遵守原插件的核心原则：笔记是唯一数据源，不写隐藏标记、不写 frontmatter，不把导图数据存到插件外部；列表 marker 也不会被无故改写。

### 原版功能

- **双向编辑**：支持节点新增、改名、删除和拖拽重排，正文随所属标题移动；写回仅替换相关行范围，保留范围外的内容与格式。
- **浏览与定位**：点击节点定位可见笔记，支持阅读模式；搜索结果可定位并高亮，纯导图也能撤销／重做。
- **笔记与导图互转**：在同一标签页切换，并可记住每篇笔记的打开方式。
- **按需展示**：默认只显示标题，可开启列表节点；支持行内格式、链接文字和公式。本 fork 另外支持有序列表和上述安全内联 HTML。
- **样式与布局**：自定义形状、配色、字号、间距、连线及布局方向，支持全局／单篇设置、实时预览和取消还原。
- **便捷操作**：快捷键、平滑动画、按笔记锁定、缩放与位置记忆，以及触屏双指缩放和平移。

一次导图操作对应一步撤销。笔记编辑器使用原生历史；纯导图使用有容量上限的会话历史，检测到外部修改时拒绝覆盖。

## 安装

本 fork 不在 Obsidian 社区插件市场，需要手动安装：

1. 在本 fork 源码目录构建：

   ```bash
   npm ci
   npm run build     # 类型检查 + 打包出 main.js
   ```

2. 把 `main.js`、`manifest.json`、`styles.css` 放进
   `<你的仓库>/.obsidian/plugins/outline-mindmap/`。
3. 在「设置 → 第三方插件」里启用「Outline Mindmap」。

本 fork 也把构建好的 `main.js` 和 `styles.css` 提交在仓库里，方便直接复制；它们仍是生成产物，
修改源码后需要重新构建。上游的 Release 资产如果存在，属于原版 v1.3.4，不包含本 fork 的这些增强。

## 使用

打开导图有四种方式：

- 左侧栏的导图图标 → 在**右侧边栏**打开
- 命令面板「打开导图」→ 在**主页面区**新标签页打开
- 命令面板「在侧边栏打开导图」
- 笔记右上角三个点 →**「打开为导图」**：当前这个标签页就地变成导图
  （文件列表里右键笔记也有这一项）

导图菜单中的「打开为笔记」可在同一标签页切回笔记，恢复原来的阅读／编辑模式。

- **跟随型导图**：侧边栏图标和命令面板打开的导图跟随活动笔记；设置「固定显示一篇笔记」可使其停留在同一篇。
- **单篇导图**：「打开为导图」将笔记标签页就地转换，只显示该篇笔记。可记住打开方式，形态切换不进入标签页历史。

纯导图中单击节点只会选中，不会另开笔记。需要同时阅读正文时，请在侧边栏或分栏中打开导图；点击定位仅作用于已经可见的笔记。

### 笔记怎么变成导图

| 笔记里的写法 | 导图里的层级 |
| --- | --- |
| `# 标题` … `###### 标题` | 第 1–6 层 |
| `- 列表项` / `1. 列表项`（一层缩进 = 4 个空格或一个 Tab） | 第 7 层起（可用「把列表项显示为节点」关掉） |
| 标题下面的正文段落 | 不是导图节点；悬停标题或用工具栏固定预览查看，正文仍**跟着标题一起移动** |
| 代码块里的 `#` | 不是标题，不会出现在导图里 |

节点文字里的 `**粗体**`、`*斜体*`、`***粗斜***`、`==高亮==`、`~~删除线~~` 会照着渲染，
可以任意嵌套；没配对的 `*`（比如 `2 * 3`）当普通文字，不会被吃掉。

节点中的 `$...$` 行内公式会交给 Obsidian 自带的 MathJax 渲染，可以与普通文字和
其他行内格式混排；公式有误时会退回可编辑的源码，不会拖垮整张导图。
`$$...$$` 块公式仍属于笔记正文，不会被当成节点内的行内公式。

链接只显示**可读的那部分**，路径和 URL 不占节点宽度：

| 笔记里的写法 | 导图里显示 |
| --- | --- |
| `[[某笔记]]` | 某笔记 |
| `[[文件夹/目标\|别名]]` | 别名 |
| `[[笔记#小节]]`、`[[#小节]]` | 小节 |
| `[文字](https://…)` | 文字 |

链接文字会用主题的链接色标出来，但**不可点击**——导图里的单击已经用于跳到笔记对应行，
再抢一次点击只会让人猜不准点下去会发生什么。

### 节点正文预览

鼠标在节点上停留约 0.3 秒，会预览该节点的**直接正文**——标题/列表项之后、第一个子标题/子列表项之前的内容。预览由 Obsidian 的 `MarkdownRenderer` 渲染，因此 HTML、图片、公式、Markdown/HTML 表格和内嵌内容的表现与阅读视图一致。

- 鼠标可以移进预览面板继续滚动查看，移出节点和面板后自动收起。
- 触屏设备上**长按节点 500ms** 会显示视图上方的正文预览（位于 Obsidian 导航栏和导图工具栏下方）；松手或移动超过 10px 取消。手指碰到预览面板后，面板会保留，方便连续滑动正文；点关闭键或画布收起。桌面端悬停行为不变。
- 工具栏固定的预览与长按预览是**两个独立面板**，可以同时存在；固定面板左上角的手柄可拖动调整宽高。
- 点击图钉按钮可固定为右侧面板；触屏上使用工具栏眼睛按钮打开持久预览。
- 工具栏眼睛按钮可为当前选中节点打开/关闭固定预览。
- 设置「悬停预览正文」默认开启，只控制桌面端自动悬停；移动端长按仍可使用。
- 预览是**只读**的，不会修改笔记；编辑仍在笔记源码中进行。
- 预览只包含节点自己的直接正文；子标题属于子节点，请分别悬停查看。

预览里的内部链接会在新标签页打开。正文预览不会改变节点布局，也不会把正文内容变成导图节点。

### 节点内联 HTML

节点标题支持一组安全的内联 HTML，例如：

```md
- <span style="background-color: #4472C4; color: white; padding: 4px 8px; border-radius: 4px;">微指令的设计</span>
```

支持的标签包括 `span`、`font`、`mark`、`strong`、`b`、`em`、`i`、`u`、`s`、`sup`、`sub`、`br`、`code`、`kbd`、`small`、`abbr` 等内联标签；支持颜色、背景、padding、margin、边框、圆角、字号/字重/字体样式、行高等有限 CSS。脚本、iframe、事件属性、`url()` 和块级 HTML 会被拒绝。

F2 / 双击仍然编辑原始 Markdown 源码。节点标题里不支持完整 HTML 表格和图片；这些内容请放在正文预览中查看。

### 有序列表

有序列表项作为普通列表节点显示，不显示序号；节点上下顺序跟随正文。

- 重命名、移动时保留源码中的原始 marker。
- 新建有序项的兄弟节点继承参考项的 delimiter，写 `1.` 或 `1)`。
- 新建有序项的子节点固定写 `-`（无序）。
- 不自动重排源码编号。
- 开启「按层级着色」时，文字仍按层级着色；边框和背景使用列表类型强调色。`1.` 使用实线和较淡背景，`1)` 使用虚线和稍深背景。

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` | 上一个 / 下一个节点：先找同级兄弟，没有了就退到外层 |
| `→`（「进入」方向） | 分支收着就展开它，已经展开就进到第一个子节点 |
| `←`（「返回」方向） | 分支展开着就收起它，已经收起（或没有子节点）就回到父节点 |
| `Enter` | 在当前节点后面新增一个兄弟节点 |
| `Tab` | 给当前节点新增一个子节点 |
| `F2` / 双击节点 | 重命名 |
| `Delete` / `Backspace` | 删掉选中的节点及其整棵子树 |
| `Ctrl/⌘ + Z` | 撤销（仅打开导图也可使用） |
| `Ctrl/⌘ + Shift + Z` / `Ctrl + Y` | 重做 |
| `Esc` | 放弃当前编辑或当前拖拽，笔记一个字都不写 |
| 双击空白处 | 新建一个自由根节点 |
| `Ctrl/⌘ + 左键` | 加选 / 减选（用于一次删掉一批） |
| 拖拽节点 | 重排：拖到节点上下缘 = 插到前 / 后，拖到中间 = 成为它的子节点，拖到空白 = 变成新的根 |
| 滚轮 | 平移；按住 `Ctrl/⌘` 滚 = 以鼠标为中心缩放 |

方向键的左右是**按节点自己朝哪边生长**来解释的：分支向左时，`←` 才是「进到子节点里去」。

### 工具栏

适应画布 · 缩小 · 放大 · 展开全部 · 折叠全部 · 预览正文 · 锁定 · 样式设置。

**布局方向**（向右 / 向左 / 两侧）移入样式设置，与其他样式一样支持全局、单篇保存、实时预览和取消还原。

**锁定状态按笔记记忆**。锁定后，仍可平移、缩放、展开折叠、点击定位和调整样式；
笔记端的修改仍实时显示，但不能从导图新增、改名、删除、拖动节点或撤销／重做。
**阅读模式强制锁定**，返回编辑模式后恢复原来的手动锁定状态。
同篇笔记同时打开多个视图时，可见的阅读视图优先；从阅读视图转换成纯导图也会继承阅读模式，
可通过「打开为笔记」返回笔记并切换模式。

**每篇笔记记忆缩放比例与浏览位置**，重启后也能恢复。画布大小改变时，之前浏览的坐标仍位于中央。
如果笔记变化后旧位置已看不到节点，会保留缩放比例并移到附近的节点。
展开／折叠状态仍不持久化，因此布局变化后不能保证同一个节点仍在原位置。

触屏支持**双指缩放与平移**。第二根手指落下会取消尚未完成的节点拖动，手势结束不会顺带点击或编辑节点。
锁定状态下，单指可以从节点或空白处平移；轻点仍可选中和定位。

「分支两侧」会把根节点的子分支**按子树规模**均衡分到左右两列。

## 设置

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| 单击即跳转 | 开 | 单击节点时，把屏幕上的笔记在编辑模式或阅读模式中滚到对应标题或列表项并高亮（焦点始终留在导图上）；在导图里新建 / 重命名 / 删除 / 拖拽之后，笔记也停在那个节点处。**只滚屏幕上已经露着的笔记**——不新开标签页、不分栏、不把后台标签切到前台。关掉后单击只选中 |
| 悬停预览正文 | 开 | 鼠标悬停节点时，用 Obsidian 的 MarkdownRenderer 只读预览该节点的直接正文；支持 HTML、图片、表格、公式和内嵌内容。关闭后不再自动悬停预览，工具栏眼睛按钮仍可打开固定预览 |
| 固定显示一篇笔记 | 关 | 导图不再跟着你切换笔记，一直停在打开它时的那一篇 |
| 优雅动画 | 开 | 节点与连线同步过渡；超过 250 个可见节点或系统要求减少动态效果时关闭动画 |
| 严格换行 | 关 | 新增 / 移动节点时，相邻两个标题之间补足 3 个空行 |
| 把列表项显示为节点 | 关 | 关掉后导图只画标题，列表项回归为标题下的正文。笔记本身一个字节都不动，再打开即恢复原样。关着时，会把节点推过标题第 6 层的操作（第 7 层没有可见的写法）会被拦下并提示 |
| 大图性能模式 | 自动 | 自动：移动端总节点超过 500 时启用，桌面端自动保持完整渲染；开启：始终启用；关闭：始终完整渲染。启用后首屏显示可读局部，只渲染视口附近的节点和连线 |
| 记住每篇笔记的打开方式 | 开 | 用「打开为导图」转换过的笔记，下次在任何标签页里打开都直接显示为导图；「打开为笔记」即恢复，并还原转换时的阅读 / 编辑模式。记录只存在插件的 `data.json` 里，改名 / 移动 / 删除笔记时自动迁移或清理。形态切换不进入标签页历史，「后退」「前进」只在笔记之间移动 |

样式（形状、配色、**按层级着色**、字号、横纵间距、分支样式：**直线 / 斜线 / 折线**）
分**全局**与**单篇**两级：
单篇没设就用全局的。样式窗口开着时拖滑块会实时预览，取消即还原。
单篇样式的键是文件路径，重命名 / 移动 / 删除笔记时会自动迁移或清理。

有序列表和无序列表一样作为节点显示，但**不显示序号**；打开「按层级着色」时，有序列表节点的文字仍按层级着色，边框和背景使用另一种列表类型颜色。`1.` 使用实线和较淡背景，`1)` 使用虚线和稍深背景。有序项的源码 marker（如 `1.`、`2)`）在重命名 / 移动时原样保留；新建有序兄弟项继承参考项的 delimiter，写 `1.` 或 `1)`，新建有序项的子项写 `-`，不自动重排编号。

## 性能

平移与缩放只更新容器变换，连线合并绘制，节点事件统一委托。超过 250 个可见节点或系统要求减少动态效果时，自动关闭动画。

**大图性能模式（1.5.0）**：

- 默认在**移动端总节点超过 500** 时自动启用；桌面端自动模式不变。设置页可改为「始终开启」或「关闭」。
- 首次打开大图不再把整张图缩到看不清，而是以 0.9 的缩放聚焦第一个根分支；旧版本保存的极远视野会保留中心点并抬到可读比例。
- 只创建视口附近（含 240px 预渲染边距）的节点 DOM；连线只为实际渲染的子节点生成入边。平移或缩放后合并到下一帧重新裁剪。
- 当前阶段只在性能模式下做节点/连线裁剪；缩放到整图全景时仍会渲染全部节点，轻量全景和延迟富文本将在下一阶段实现。

仓库附带 [1000 节点压力测试笔记](bench/1000节点压力测试笔记.md)。自动化测试覆盖解析、布局与编辑；真实渲染耗时可在 Obsidian 中通过「性能自检」查看。「跟随自检」用于排查导图未跟随活动笔记的问题。

## 已知限制

- 导图本身仍以大纲文字为主：节点标题是纯文字加安全内联 HTML，不是每个节点里的完整 Markdown/HTML 页面；块级 HTML、表格、图片请放在只读的正文预览里看。
- 正文预览只显示节点的**直接正文**（到第一个子节点之前）；子节点有自己的正文，需要分别悬停。预览只读，不会写回笔记。
- 有序列表不显示序号；插入、删除、拖拽后不会自动重排源码编号。
- 折叠状态不持久化，切换笔记即重置。
- 性能模式当前只做视口虚拟化；缩放到整图全景时仍会渲染全部节点，轻量全景和延迟富文本将在后续阶段实现。
- 任务列表 `- [ ]` 按普通文本处理。
- 多选（`Ctrl/⌘ + 左键`）只用于批量删除，不支持批量拖拽移动。

## 开发

```bash
npm run dev        # 监听构建
npm run typecheck  # 严格模式类型检查
npm test           # 单元测试 + 集成测试
```

`core/` 与 `layout/` 保持为不依赖 Obsidian 的纯逻辑；`doc/` 负责文档读写与笔记视图集成，`view/` 负责导图交互，`settings/` 管理设置、样式与偏好。

开发时不必每轮手动复制三个文件，头一次指定仓库，之后一条命令：

```bash
npm run deploy "D:\某个仓库"   # 记住这个目标（写进 deploy.json，不进版本库）
npm run deploy                 # 之后：构建 + 装进记住的仓库
```

它只覆盖 `main.js`、`manifest.json`、`styles.css`，不碰 `data.json`，更不碰笔记。
仓库里若已经有一个目录名不叫 `outline-mindmap` 的同款插件，它会复用那个目录，
不会另建一份 id 相同的出来。

发布前运行 `npm test` 和 `npm run build`，统一 `manifest.json`、`package.json`、
`package-lock.json` 与 `versions.json` 的版本。本 fork 的发布版本是 `1.5.0`，上游基础版本仍是 `1.3.4`。
若要发布 Release 资产，将 `main.js`、`manifest.json`、`styles.css` 作为附件上传。
**tag 不要带 `v` 前缀**——Obsidian 按纯版本号找 release。

## 更新说明

### 本 fork v1.5.0

- **大图性能模式**：新增设置项「大图性能模式」，默认自动。移动端总节点超过 500 时启用；桌面端自动模式仍完整渲染，可手动开启。
- **可读局部首屏**：性能模式下不再把整张图缩到极小，而是以 0.9 缩放聚焦第一个根分支；旧版保存的极远视野会保留中心点并抬到可读比例。
- **视口虚拟化**：只渲染视口附近（含 240px 预渲染边距）的节点，平移 / 缩放后按帧合并更新；连线只为实际渲染的子节点生成。
